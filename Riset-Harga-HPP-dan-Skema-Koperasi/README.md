## Peringatan Metodologi Umum

Data harga (file 01–05) **dikompilasi dari pemberitaan media dan literatur akademik sekunder**, bukan dari satu database resmi/kontinu. Setiap file mencantumkan catatan metodologi dan tingkat keyakinan datanya masing-masing. **Semua angka wajib divalidasi dengan data primer** (Bappebti, Disperindag Aceh, ARC Universitas Syiah Kuala, atau data transaksi Trading Center KANANTARA sendiri) sebelum dijadikan dasar keputusan investasi atau kebijakan resmi koperasi.

## Temuan Kunci (Highlight)

1. **Volatilitas harga tinggi**: harga nilam bergerak dari ± Rp 500.000/kg (2022) hingga Rp 2.300.000/kg (akhir 2024) dalam rentang 5 tahun — rasio lebih dari 4x.
2. **Harga "normal" jangka panjang (modus) ± Rp 700.000–900.000/kg** — jauh di bawah asumsi harga jual Rp 1.500.000/kg pada simulasi 5 tahun bundel utama; disarankan menambahkan skenario konservatif.
3. **HPP riil petani (cash cost) jauh di bawah Harga Dasar KANANTARA** — risiko utama bukan petani rugi absolut, melainkan **KANANTARA gagal menjaga janji Harga Dasar** saat pasar anjlok (lihat file 09).
4. **ALKO (rujukan replikasi model) adalah entitas nyata**: ALKO Sumatra Kopi, koperasi kopi di Kerinci dengan ± 9.181 petani anggota, peraih Top 50 Cooperative & SME Export Awards 2026 — lihat detail di `01-Konsep-Replikasi-ALKO.md` (folder induk, sudah diperbarui dengan temuan ini).
5. **Dana Stabilisasi 5% yang sudah diasumsikan di model dasar cukup solid**, namun disarankan diubah dari skema flat menjadi **skema progresif/kontra-siklikal** (lebih besar saat harga tinggi, lebih kecil saat harga rendah) agar dana tidak lemah justru saat paling dibutuhkan (lihat file 09).
6. **BPJS + asuransi gagal panen + beasiswa pendidikan layak dan terjangkau** (± 0,4% dari omzet Tahun 1 untuk BPJS saja), dengan syarat dikelola via entitas Yayasan terpisah dari koperasi dan beasiswa dirancang berkuota (bukan jaminan blanket) — lihat file 08.
